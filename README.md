# Currency Converter App

A simple and user-friendly currency converter application built with React and powered by the Free Currency API. This app allows users to easily convert currencies in real-time.

## Features

- **Real-Time Currency Conversion**: Get up-to-date exchange rates and convert amounts between different currencies.
- **Interactive Interface**: Select the source and destination currencies, enter an amount, and get the conversion result instantly.
- **Supports Multiple Currencies**: Currently supports USD, EUR, and TRY as the base and target currencies.
  
## Technologies Used

- **React**: Frontend framework to build the user interface.
- **Axios**: Used for making HTTP requests to fetch real-time exchange rate data from the Free Currency API.
- **CSS**: For styling the application.
  
## Installation

### Prerequisites

- Node.js and npm (Node Package Manager) should be installed on your machine.

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/ipekdede/currencyConverter.git


2. Navigate to the project directory:

   ```bash
   cd currencyConverter

3. Install the dependencies:

   ```bash
   npm install

4. Run the development server:

   ```bash
   npm run dev

5. Open the app in your browser at http://localhost:5173

### Usage

- Enter the amount you want to convert in the input field.
- Choose the source currency from the dropdown (USD, EUR, or TRY).
- Choose the target currency (USD, EUR, or TRY).
- Click Convert to get the result.
